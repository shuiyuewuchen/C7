## 快速开始

```bash
# 1. 把任意一篇 Markdown 转成公众号 HTML
python3 05_过程文档/md2wechat.py \
  01_文章内容/赵心皓_C7_3小时译完12万字斯坦福讲义.md \
  02_排版HTML/我的文章.html

# 2. 发布后回填真实数据 → 一键重渲染看板（DEMO 水印自动变 REAL DATA）
python3 05_过程文档/rebuild_dashboard.py
swift 03_配图素材/render_data_dashboard.swift
swift 03_配图素材/render_growth_curve.swift
#    先编辑 04_传播与数据/赵心皓_C7_数据追踪表.csv，填「7日阅读」等列；
#    可选填 D1..D7 逐日累计阅读，未填则按 24h→7日 插值并在图面标注。

# 3. 重新生成文章配图
swift 03_配图素材/render_article_diagrams.swift
```

> 所有脚本都使用**仓库相对路径**：clone 后在根目录直接运行即可，无需改动任何绝对路径。
